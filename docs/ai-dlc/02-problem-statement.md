# Problem Statement

Work often starts in email, but execution happens across memory, chat, calendars, documents, and personal notes. Workers frequently lose time reconstructing context:

- What meeting is this about?
- Where and when is it?
- Who is involved?
- What do I need to prepare?
- What is the real deadline?
- Which email triggered this work?

Traditional task tools require users to classify information up front. In real work, users often only have enough time to write a rough memo.

## Target Problem

Users need a fast way to attach rough notes to an email and let AI organize the work context into dates, places, people, deadlines, and tasks.

## Current Alternatives

- Gmail labels: good for mail organization, weak for rough work notes.
- Calendar: good for scheduled events, weak for preparation tasks.
- Todo apps: good for explicit tasks, weak for messy email context.
- OneNote/Notion: flexible, but structure depends on manual discipline.

## Desired Outcome

A user should be able to paste or import an email, write an imperfect memo, and get an editable structured work summary within seconds.

## Non-Goals For MVP

- Full calendar synchronization
- Sending emails from the app
- Enterprise-wide search
- Multi-user collaboration
- Automatic background email scanning without explicit user consent
