# Vision

ContextPad helps busy knowledge workers turn messy work communication into actionable context without forcing them to maintain a perfect task-management system.

The product behaves like a lightweight memo pad first. Users can write incomplete notes such as:

```text
担当Aさん参加。前回資料確認。SaaS棚卸しのところ聞く。
明日午前中ドラフト作る。9/17 14:00 オンライン。
```

ContextPad links that rough note to a related email and produces a structured view:

- Date and time
- Place
- People
- Deadline
- Tasks
- Related email
- Summary and next action

## Portfolio Goal

This project demonstrates practical AI-driven development:

- Requirements and design are captured before implementation.
- AI-generated proposals are reviewed by a human.
- The architecture maps to realistic AWS services.
- The MVP remains small enough to ship, test, and explain in an interview.

## Product Principles

- Memo first, task manager second.
- The user can be rough; the system should organize.
- AI output must be reviewable, editable, and explainable.
- Email content is sensitive; security and auditability are core requirements.
- The first release should be useful locally before cloud complexity is added.
