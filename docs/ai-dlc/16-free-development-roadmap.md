# 無料構成と次の工程

日付: 2026-09-14 / 状態: SQLite保存まで実装、その他の工程は以下の状態を参照

## 人間からの要求

「無料で作成できるものですべてお願いします。このあとの動きとしてはなにありますか」

追加のサービス利用料を0円に抑える。期間限定クレジットを使い切った後に課金される構成を前提にしない。既存PC・通信・電力や、ユーザーが別途契約している開発支援ツールの料金まで無料になるとは意味しない。

この制約は、初期資料のAWS/Bedrock実稼働案より優先する。AI-DLCの成果物・人間レビュー記録は引き続き残すが、AWSを動かした経験を未実施のまま実績として記載しない。

SQLiteは無償利用できるローカルDBで、現在の個人用試作版に対する次段階の選択とする。[SQLiteの利用条件](https://www.sqlite.org/copyright.html)

端末内生成AIの候補としてOllamaなどがあるが、クラウド機能を使わず、使用モデルのライセンス・メモリ・処理時間を確認してから判断する。自動で大容量モデルを導入したり、性能不足を理由に有料APIへ切り替えたりしない。[Ollama公式FAQ](https://docs.ollama.com/faq)

## 無料の境界

Gmail APIの標準利用には追加料金がないが、Googleは2026年後半に上限超過への課金導入を予定している。現在の公式資料では日次の課金しきい値や分単位の上限が示されており、利用条件は接続時に再確認する。無制限・永久無料とは扱わない。課金アカウントのリンクや有料枠の有効化を求められた場合は進めずに確認する。[Google公式の料金・上限](https://developers.google.com/workspace/gmail/api/reference/quota)

Gmail接続の一般公開は別工程。gmail.readonlyはrestricted scopeであり、公開形態やサーバーでの保存・送信には確認・セキュリティ評価の要件がある。実Gmailを扱う公開サービス全体が無料で成立するとは保証しない。[Google公式スコープ資料](https://developers.google.com/workspace/gmail/api/auth/scopes)

Bedrockには推論の従量料金があるため、この無料構成では呼び出さない。AWSリソースも無料トライアルを前提に作成しない。[Bedrock料金](https://aws.amazon.com/bedrock/pricing/)

GitHub Actionsは公開リポジトリの標準ランナーで無料利用できる一方、非公開リポジトリには枠があり、大型ランナー等には別の条件がある。無料にするために勝手にリポジトリを公開せず、公開範囲・上限・支払い設定を先に確認する。[GitHub公式の課金条件](https://docs.github.com/en/billing/concepts/product-billing/github-actions)

ユーザーの「上から順にお願い」を受け、ポートフォリオ準備として提示した順序へ更新する。設定や外部情報が必要な項目は未完了と明示し、独立したローカル作業は継続できる。

2. Gmailの設定と実接続確認。Google CloudのOAuth設定・同意が必要。手順は[Gmail設定](../gmail-setup.md)。認証情報未設定のため実接続は待機。

4. 主な利用フローの自動テストとCI検証。50件のAPIテストとWebビルドをローカル確認。CI設定更新済み、GitHub実行はリモート未登録のため未確認。
5. ポートフォリオ化。[概要](../portfolio.md)、架空データの画面例、[90秒デモ手順](../demo.md)、テスト結果と設計判断を整備。動画の録画は未実施。GitHub公開は秘密情報・実メールの検査とユーザーの公開意向確認後に行う。

その後の改善候補は、抽出結果の手直し・根拠表示・相対日時、必要性を判断した上でのローカル生成AI。実業務利用は、利用者・端末のアクセス制御、所有者分離、保持・削除、ログ保護を確認する別工程とする。

インターネットへ公開するURLは上記と別に検討する。現在の127.0.0.1は本人のPC用URLである。無料ホスティングは停止・容量・用途・認証の制約があるため、費用と安全性を確認できるまで外部公開しない。公開デモを作る場合は実Gmailと分離した架空データ版を第一候補とする。

## 実施前の確認

- 料金登録・従量課金・有料プラン・独自ドメイン購入を勝手に行わない。
- 無料枠超過時は停止し、有料枠に自動移行しない。ローカル処理や手入力で継続する。
- SQLiteは追加実装済み。生成AI・実Gmail・AWSを検証済みとは扱わない。
- 外部アカウントの課金設定や利用枠を、今回の確認だけで調査・変更済みとは扱わない。
